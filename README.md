# Football Players App

A React project created with **Vite** and **Tailwind CSS**.
The application displays a list of football players using reusable React components and props.

## 🚀 Technologies

* React
* Vite
* Tailwind CSS
* JavaScript

## 📁 Project Structure

```text
src/
├── components/
│   ├── Player.jsx
│   └── PlayersList.jsx
├── App.jsx
├── main.jsx
├── index.css
└── players.js
```

## ✨ Features

* Displays 4 football players
* Player information stored in `players.js`
* Reusable `Player` component
* Props and destructuring
* Default props
* `.map()` to display all players
* Spread operator for passing props
* Responsive player cards
* Tailwind CSS styling

## ⚙️ Installation

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite.

## 🏗️ Build

```bash
npm run build
```
